# 🎮 Hangman Game – Python

A simple and interactive **Hangman Game** developed using **Python and Tkinter**.  
The player has to guess the hidden word one letter at a time within a limited number of attempts.

## 📌 Project Overview

This project is a beginner-friendly Python GUI application that demonstrates the use of:

- Python programming
- Tkinter GUI
- Random word selection
- Loops and conditional statements
- Functions and classes
- Sets and strings
- Event-driven programming

## 🎯 Objective

The main objective of this project is to develop an interactive Hangman game where the player guesses a randomly selected word by clicking letter buttons.

The player gets a maximum of **6 incorrect guesses**. The game ends when the player successfully guesses the word or runs out of attempts.

## ✨ Features

- 🎮 Interactive graphical user interface
- 🔤 A-Z letter buttons
- 🎲 Random word selection
- ❤️ Maximum 6 incorrect attempts
- 📝 Displays guessed letters
- 🏆 Win message when the word is guessed
- ❌ Game-over message when attempts are exhausted
- 🔄 New Game button
- 🚫 Already selected letters are disabled
